### Building Agentic AI Systems: From LLMs to Autonomous Agents
- **Workshop ID:** WS-001
- **Category:** Artificial Intelligence
- **Date & Time:** Thursday, Nov 12, 2026, at 14:00
- **Location / Venue:** Main Auditorium - Faculty of Sciences, Saad Dahleb University of Blida
- **Instructor / Speaker:** ITC AI Team Lead
- **Capacity:** 80 seats
- **Prerequisites / Requirements:** Basic Python knowledge, laptop required, free account on an LLM provider (a free-tier API key will be explained during the session)
- **Detailed Content & Agenda:**
  - Understanding the difference between a simple chatbot, an LLM workflow, and a true autonomous agent
  - Core components of an agent: system prompt, memory, tools, planning loop, and guardrails
  - Tool calling and function calling: letting an agent search the web, query a database, and send messages
  - Building a first working agent in Python that can reason step by step and decide which tool to use
  - Introduction to multi-agent patterns (planner and executor, supervisor and workers)
  - Evaluating agent behavior, handling hallucinations, and applying safety limits
  - Live demo of an agent handling a customer support scenario, followed by Q&A
- **Target Audience:** Intermediate members with basic programming experience; motivated beginners are welcome
